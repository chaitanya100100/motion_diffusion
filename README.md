# modiff: Conditional Human Motion Diffusion

`modiff` is a small, hackable codebase for training and sampling **conditional human motion diffusion models**
on [AMASS](https://amass.is.tue.mpg.de/) (SMPL-X). It grew out of
[UniEgoMotion](https://chaitanya100100.github.io/UniEgoMotion/) (ICCV 2025) and is the motion prior used in
[EgoMo3R](https://chaitanya100100.github.io/EgoMo3R/) (NeurIPS 2026). **If you find this code useful, please cite UniEgoMotion and EgoMo3R** (see [Citation](#citation)).

A motion sequence is generated by denoising a fixed-length window of per-frame body features, optionally
conditioned on

- a **head (egocentric camera) trajectory**: trajectory-to-motion,
- a **text prompt**: text-to-motion,
- or nothing: unconditional generation (each condition is dropped with p=0.1 during training, so
  classifier-free guidance via `cond_scale` is also supported).

## Installation

```bash
conda create -n modiff python=3.10 -y && conda activate modiff
# install PyTorch for your CUDA version from https://pytorch.org first
pip install -r requirements.txt
pip install -e .
```

`assets/exact_requirements.txt` lists the exact versions we used.

## Pretrained model for EgoMo3R's motion prior

EgoMo3R's motion prior (`configs/amass_v1_ait_unet.yaml`) is a 1D temporal UNet (`uem_unet`) that generates SMPL-X
motion (`v1_ait` representation) from a head trajectory. The trajectory is centered on its first frame, so no floor
or gravity is needed.

> If you came here to run the **full EgoMo3R pipeline** (joint motion and scene reconstruction from an egocentric
> video), set up this repository first and then follow the README of
> [chaitanya100100/EgoMo3R](https://github.com/chaitanya100100/EgoMo3R), which installs into this same environment.

1. **SMPL-X.** Register at https://smpl-x.is.tue.mpg.de and put `SMPLX_NEUTRAL.npz` at
   `data/smpl_data/smplx/SMPLX_NEUTRAL.npz`.
2. **Checkpoint and normalization statistics** from
   [Hugging Face](https://huggingface.co/chaitanya100100/egomo3r-motion-prior):
   ```bash
   hf download chaitanya100100/egomo3r-motion-prior --local-dir data --include "checkpoints/*" "processed/*"
   ```

This gives:

```
data/
  smpl_data/smplx/SMPLX_NEUTRAL.npz
  checkpoints/amass_v1_ait_unet/{hparams.yaml,last.ckpt}
  processed/v1_ait_amass_w80_stats.pt
```

### Sanity check

```bash
python modiff/run/sanity_check.py               # add --video ./vis to render the result
```

This generates motion for an example 8 s head trajectory (`assets/example_head_traj.npy`) and should print a head
position error of about 2.5 cm. `modiff/run/sanity_check.py` is also a minimal example of how to use the prior:
`UEM_Module.from_pretrained`, then `model.sample` for 80-frame windows or `model.sample_long` for any length.

## Training EgoMo3R's motion prior yourself

The prior is trained on the AMASS SMPL-X N and SMPL-X G subsets at 10 fps with zero betas. Download both from
https://amass.is.tue.mpg.de and extract them as `$AMASS/smplx_n/<dataset>/...` and `$AMASS/smplx_g/<dataset>/...`.

```bash
AMASS=/path/to/amass
OUT=data/processed

# 1. process each AMASS subset
python -c "from modiff.run.process_amass import process_data; process_data()" \
    --amass_root $AMASS --out_dir $OUT --source_amass_ds_type smplx_n --zero_beta
python -c "from modiff.run.process_amass import process_data; process_data()" \
    --amass_root $AMASS --out_dir $OUT --source_amass_ds_type smplx_g --zero_beta

# 2. merge them
python -c "from modiff.run.process_amass import merge_datasets; merge_datasets(\
    ['$OUT/amass_10fps_smplx_n_zerobeta_from_smplx_n.pt', '$OUT/amass_10fps_smplx_n_zerobeta_from_smplx_g.pt'], \
    '$OUT/amass_smplx_n_zerobeta_from_smplx_ng.pt')"

# 3. normalization statistics (written to data/processed/v1_ait_amass_w80_stats.pt)
python -c "from modiff.dataset.motion_datamodule import save_statistics; \
    save_statistics('v1_ait', 80, '$OUT/amass_smplx_n_zerobeta_from_smplx_ng.pt')"

# 4. train
python modiff/run/train_uem.py CONFIG configs/amass_v1_ait_unet.yaml TRAIN.EXP_PATH ./exp/amass_v1_ait_unet \
    DATA.AMASS_DATA_PATH $OUT/amass_smplx_n_zerobeta_from_smplx_ng.pt
```

Load the trained model with `UEM_Module.from_pretrained("./exp/amass_v1_ait_unet")`.

## Other models

The same pipeline trains other conditional motion models. Pointers:

- **Configs:** `configs/` has trajectory-to-motion variants (`amass_v1*`), text-to-motion models (`*_t2m.yaml`) and
  the original UniEgoMotion setup (`uem.yaml`). Train any of them with `modiff/run/train_uem.py` as above. Config
  keys and defaults are in `modiff/config/defaults.py`; any key can be overridden on the command line.
- **Models** (`MODEL.MODEL_NAME`): `uem_unet`, `uem_basic` (transformer encoder), `uem_dec` (transformer decoder
  with text cross-attention) and `uem` (UniEgoMotion). See `modiff/module/uem_module.py` and `modiff/model/`.
- **Representations** (`DATA.REPRE_TYPE`): `v1_ait`, `v1`, `v1f`, `v4`, `v5` and their `*_beta` variants. See
  `modiff/dataset/representation_utils.py`. Each (representation, window) pair needs its own statistics:
  `save_statistics(repre_type, window, ...)`.
- **Text-to-motion data:** mirrored sequences (`modiff/dataset/smpl_mirroring.py`), BABEL / HumanML3D / KIT-ML
  annotations (`text_anns_smplh_to_smplx()` in `process_amass.py`) and pre-encoded text features
  (`TextFeats.preencode_all_texts()` in `modiff/dataset/feats.py`).
- **Visualization:** `modiff/run/vis_uem.py` renders predictions vs. ground truth on AMASS validation sequences.
- Paths used only for these setups point to our cluster and are marked with `TODO` comments.
